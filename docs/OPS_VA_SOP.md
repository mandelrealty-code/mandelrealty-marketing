# VA / ops day-to-day — work from Admin Tasks

You do **not** need to open five apps every morning. Start here:

**Admin → OPS → Tasks**  
`https://admin.mandelrealtygroup.com/ops`

## What you see

- **Attention** strip at the top: overdue, high priority, supply, cleaning QA, properties missing links.
- The task list below is your queue.

## How work shows up (automatic)

| Signal | What appears in Admin |
|--------|------------------------|
| Guest review ≤4★ (after Hospitable sync) | High-priority review task |
| Cleaner reports low stock | Supply reorder task |
| Cleaner finishes a turnover | Cleaning QA task |

## Your loop

1. Open **Tasks**.
2. Clear **Overdue** and **High** first.
3. Open a task → read the note → mark done or blocked.
4. Need the unit? Open the property → **App links**:
   - **Create / open in Cleaner Hub** for rooms, checklists, inventory
   - **Open** Hospitable (needs dashboard id saved once under Edit links)
   - Guidebook only if that unit has a guest guidebook

## What is *not* your job in this queue

- Guest chat day-to-day → CohostAI / Hospitable inbox (escalate only when a task says so)
- Entering inventory counts → cleaners in Cleaner Hub
- Owner money math → Month close / Shane

## Linking a new property (once)

1. Admin → Properties → Import from Hospitable  
2. **Create / open in Cleaner Hub**  
3. Edit links → paste Hospitable URL or numeric id so **Open** works  
4. Guidebook only if needed
