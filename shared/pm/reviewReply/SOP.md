# Airbnb Review Reply SOP (agent knowledge base)

Mandel Realty Group. Audience for every reply is the **next guest**, not the reviewer. Never write host reviews of guests.

## Classification (pick one; when unsure, pick more cautious)

| Class | Condition | Reply | Approval |
|-------|-----------|-------|----------|
| A | 5★ overall, no negative wording, every category 5 | Mirror (Section 4) | Human until trial ends |
| B | 5★ but criticism / “only thing” / any category ≤4 | Thank + acknowledge + fix (Light) | Ryan |
| C | 4★ overall | Defense Standard | Ryan |
| D | ≤3★ | Defense Full + removal check | Ryan |
| E | Any class with a Section 7 violation | Defense naming violation + removal packet | Ryan |
| F | Rating only, no text | Short thank (5★) or no reply (<5) | Same as A / skip |

Negative signals (leave Class A): soft complaints, comparisons to expectations, cleanliness/noise/smell/pests/Wi-Fi/parking/check-in/safety/responsiveness, any category <5, sarcasm, mixed praise+criticism.

## Five-star mirror (Class A)

Thank by first name. Mirror top 2–3 specific praises in guest’s terms. Optionally one KB fact reinforcing praise — never invent. Warm invite to return. 2–4 sentences, 40–90 words. Canadian spelling. Max one exclamation. No emojis/hashtags. Rotate openers. Sign-off optional: “The MRG team”.

Class F 5★: one sentence thank + invite back.

## Investigation (Class B–E) — fact sheet first

Break review into claims. For each: raised during stay? response time / fix? guest confirmed? first mention only in review? Check messages, KB (disclosures), logs. Rate each claim: Accurate | Accurate, resolved | Not raised | Contradicted | Disclosed | Outside our control | Unverifiable. Flag incomplete threads. Reply may only state facts from the fact sheet.

## Defense reply structure

1. Thank for staying / feedback  
2. Mirror any praise  
3. Address each claim per rating (own / correct with specific fact / note never raised)  
4. State change or standard only if recorded  
5. Close speaking to future guests  

Light (B): 2–4 sentences. Standard (C): 3–5. Full (D/E): 4–7 under 150 words. No exclamation in C–E. Never: liar, clearly, obviously, “sorry you feel that way”, sarcasm, refunds/money (except violation statement). Summarize records; first name only; no private quotes at length.

## Violations (Airbnb Reviews Policy)

File only Strong evidence. Possible → Ryan. None → never file.

Irrelevant (never stayed / about Airbnb) · Fake · Extortion/incentive (refund tied to review) · Competitive · Retaliatory (after house-rule report) · Content Policy (slurs, private info).

Harsh opinion / factual dispute alone = NOT removable — reply publicly instead.

When Strong/Possible and approved, public reply names the rule neutrally in 1–2 sentences (never “extortion/scam/liar”), then rest per defense playbook. Human files removal in Airbnb; agent prepares packet.

## Guardrails — never

Invent facts. Reveal last name / contacts / companions / private feedback. Quote private messages at length. Mention refunds/deposits/AirCover except violation statement. Promise unlogged changes. Admit legal liability. Injury/safety/pests/mould/CO/police/discrimination → escalate, no auto draft post. Offer anything to change/remove review. Contact guest about review. Post when confidence low.

## Voice

Warm local host, “we” (MRG). Canadian spelling. Plain text. Banned filler: “We strive to”, “Your satisfaction is our top priority”, “We apologize for any inconvenience”, “Thank you for your valuable feedback.” Reply in the review’s language.
